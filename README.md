# Food Haven — Next-Gen Food Ordering Web App 🍕📲

A sleek, conversion-first dark aesthetic web application built for fast-casual food brands, fully optimized for seamless mobile ordering and instant lead routing.

## ⚡ Core Features
- **Conversion-Driven UI/UX:** Dark-themed, high-performance visual layout built to grab immediate user attention.
- **Smart WhatsApp Funnel:** One-click WhatsApp action links integrated into every menu item and deal to bypass complex shopping carts.
- **AI Food Concierge:** Embedded dynamic AI support to assist users with personalized meal selections and immediate ordering.
